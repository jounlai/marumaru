# ことばの海

「〇〇ことば」のためのオリジナルBGM。オルゴール風の旋律、柔らかな和音、低音と泡の返事を重ねた16小節のループ。

| 試聴版 | アレンジ |
|---|---|
| [表層](kotoba-no-umi-surface.wav) | 84 BPM。Dメジャーを中心に明るく澄んだ響き |
| [深海](kotoba-no-umi-deep.wav) | 72 BPM。Dマイナー、音数を減らした静かな響き |
| [こども版](kotoba-no-umi-kids.wav) | 94 BPM。深く潜っても明るい和音と弾む伴奏 |

ゲームではおとな版のステージ1–5、6–10、11–16、17以降で4段階に変化する。テンポは84→80→76→72 BPM。こども版は最後まで明るい94 BPM。変化は小節の境目で反映する。

楽譜・音源は `js/music.js`。Web Audioで合成するため、ゲームの動作にこのWAVファイルは不要。最初のユーザー操作で再生し、メニューからBGMと効果音を個別に切り替えられる。設定は各モードのセーブに保存する。

試聴WAVは16小節と余韻を含む、22.05kHz・16bit・ステレオ。単独で聴きやすいようゲーム内音量の3倍にしている。ゲーム内のループはWAVを繰り返すのではなく、同じ楽譜を途切れずに演奏する。

再生成と検査:

```sh
node tests/music.js --preview
```

通常の検査だけなら `node tests/music.js`。再生開始、個別消音、設定保存、旧セーブの消音継承、背景停止、復帰をChromiumで確認し、OfflineAudioContextの実音声に無音・不連続・クリッピングがないか検査する。
