# ことばポップ！

「〇〇ことば」のためのオリジナル・アーケードBGM。四つ打ちのキック、クラップ、跳ねるベース、裏拍のコード、きらきらしたシンセのメロディを組み合わせた16小節のループ。既存ゲームの曲や旋律は使っていない。

| 試聴版 | アレンジ |
|---|---|
| [表層](kotoba-no-umi-surface.wav) | 128 BPM。明るいDメジャーのフックと弾むビート |
| [深海](kotoba-no-umi-deep.wav) | 134 BPM。アルペジオが加わり、さらに勢いを増す |
| [こども版](kotoba-no-umi-kids.wav) | 132 BPM。高音のきらきらした伴奏が最初から入る |

おとな版はステージ1–5、6–10、11–16、17以降で128→130→132→134 BPMに変化。深海でも明るい調性とビートを保つ。後半8小節ではメロディが高い音域に移り、4小節ごとのドラムフィルで次のフレーズへつなぐ。

楽譜・音源は `js/music.js`。ドラムもWeb Audioで合成するため、ゲームの動作に音声ファイルは不要。最初のユーザー操作で再生し、メニューからBGMと効果音を個別に切り替えられる。設定は各モードのセーブに保存する。

試聴WAVは16小節と余韻を含む、22.05kHz・16bit・ステレオ。単独で聴きやすいようゲーム内音量の3倍にしている。ファイル名は以前の試聴リンクを維持するため据え置き。ゲーム内では同じ楽譜を途切れずに演奏する。

再生成と検査:

```sh
node tests/music.js --preview
```

通常の検査だけなら `node tests/music.js`。再生開始、個別消音、設定保存、旧セーブの消音継承、背景停止、復帰をChromiumで確認し、OfflineAudioContextの実音声の音量・ピーク・隣接サンプルの変化量を検査する。
